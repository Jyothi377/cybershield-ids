CyberShield IDS

A security analyst's toolkit: scan logs for attacks, search DNA motifs, check network bandwidth, and balance server load.

1Signature Scanner (KMP, Rabin-Karp) 2DNA Motif Search (Naive) 3Bandwidth Optimizer (Max-Flow) 4Server Load Balancer (Resource Allocation)

Workflow

  1. Paste network logs into the Signature Scanner. KMP and Rabin-Karp flag attack patterns.
  2. Search a DNA sequence for a motif with DNA Motif Search (naive matching).
  3. Check how much traffic the data center links can carry on the Bandwidth Optimizer.
  4. Spread stream loads across servers on the Server Load Balancer.
  5. Compare Naive, KMP and Rabin-Karp on the same input in Algorithm Comparison.
